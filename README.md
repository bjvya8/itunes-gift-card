## 五、兑换流程：拿到卡密之后做什么

整个兑换流程其实很简单，但有几个细节错了就会卡住。

**步骤一**：打开 App Store，确保当前登录的就是你要充值的美区 Apple ID（不是国区 ID！很多人这一步就错了）。

**步骤二**：点右上角头像图标，进入账户页面。

**步骤三**：找到"兑换充值卡或代码"（Redeem Gift Card or Code），点进去。

**步骤四**：选择"手动输入代码"，把 16 位兑换码完整输入。注意区分容易混淆的字符：数字 0 和字母 O、数字 1 和字母 l、数字 8 和字母 B。建议直接复制粘贴，不要手敲。

**步骤五**：点兑换，余额到账。

**几个常见报错和对应处理**：

- "无法兑换此代码"——多半是卡的地区和 ID 地区不匹配。回去确认卡的来源区。
- "此代码已被兑换"——联系购买平台客服，正规平台会重新发卡。
- "兑换时扣除税费后余额不足"——这是正常的，美区卡兑换时会按你 ID 所在州的税率预扣，如果你的地址是免税州就不会扣。

## 六、税费这件事，必须单独说

很多人第一次兑换完发现"咦，我买的 100 美元卡，到账怎么只有 92 美元？"——这就是税费。苹果在兑换礼品卡时，会根据你 Apple ID 里填写的地址所在州，按该州销售税率预扣一部分作为后续消费的税款准备金。

**解决办法**：把 Apple ID 的地址改成 **Oregon、Delaware、Montana、New Hampshire、Alaska** 这五个免税州之一。改完之后再兑换，基本就能全额到账（极少数情况下仍有小额数字服务费，但远低于州税）。

这也是为什么前面建议，自己注册美区 ID 时一开始就填免税州地址，省得后面反复改。
